# Voxara.3d: حسابداری چاپ سه‌بعدی

یک برنامه برای وب (اندروید و آیفون)، اپ اندروید و اپ iOS. همه کاربران روی داده مشترک کار می‌کنند.

## داده‌ها کجا هستند؟

- داده‌ها در فایل `db.json` داخل یک مخزن **Private** در GitHub (مثلاً `voxara-data`) نگه داشته می‌شوند.
- هر گوشی یک نسخه از داده‌ها را روی خودش هم دارد. پس برنامه بدون اینترنت هم کار می‌کند و ثبت‌ها بعداً خودکار به سرور فرستاده می‌شوند.
- اگر دو نفر هم‌زمان ثبت کنند، هیچ‌کدام کار دیگری را پاک نمی‌کند. هر ثبت روی آخرین نسخه سرور دوباره اجرا می‌شود. اگر ثبتی دیگر معتبر نباشد (مثلاً موجودی را کس دیگری فروخته باشد)، رد می‌شود و در «حساب کاربری من» نمایش داده می‌شود.
- GitHub همه نسخه‌های قبلی فایل را نگه می‌دارد (تاریخچه Commits مخزن داده).

## کاربران

| نقش | دسترسی |
|---|---|
| ادمین | همه چیز: داشبورد، سود و زیان، حساب‌ها، تنظیمات، کاربران، پشتیبان، همه اسناد همه کاربران |
| ثبت‌کننده | فروش، تولید، خرید، دریافت، هزینه، مرجوعی، فاکتور و PDF، موجودی، مشتریان. داشبورد، سود، بهای تمام‌شده، مانده حساب‌ها، تنظیمات و کاربران را نمی‌بیند. فقط اسناد خودش را می‌تواند حذف کند. |

هر سند نام ثبت‌کننده و زمان ثبت را دارد. ادمین در «همه اسناد» می‌تواند اسناد را بر اساس کاربر فیلتر کند.

محدودیت این روش: دسترسی‌ها داخل برنامه اعمال می‌شود. کسی که کد اتصال را دارد، با دانش فنی می‌تواند کل فایل داده را مستقیم از GitHub بخواند. کد اتصال را فقط به افراد مورد اعتماد بدهید.

## ساختار فایل‌ها

- `core.js`: محاسبات (همان منطق Excel نسخه ۷) و تغییرات قابل تکرار
- `sync.js`: اتصال به GitHub، صف آفلاین، کاربران و رمزها
- `pdf.js`: ساخت PDF فاکتور بدون کتابخانه خارجی
- `ui.js`: صفحه‌ها
- `.github/workflows`: انتشار وب‌اپ (`pages.yml`)، ساخت APK (`android.yml`) و ساخت IPA (`ios.yml`)
